# Innov8 Landing Pages

This repository contains landing pages and web components developed for Innov8, including specialized event invitations and landing page elements.

## Projects

### Datadog Executive Roundtable Invitation
Located in the `datadog-landing-page` directory, this project is a premium, corporate-style event invitation built with Next.js and Tailwind CSS. 

Features:
- Responsive, polished UI with dynamic premium gradients
- Interactive event agenda modal
- Partner logos (Datadog & Innov8) integration

**To run the invitation page locally:**
```bash
cd datadog-landing-page
npm install
npm run dev
```

### Landing Page Components
Throughout the development of the Innov8 landing pages, several interactive and dynamic React components have been built and optimized, including:
- **HeroScrollVideo**: A responsive, scroll-linked animated video component maintaining correct aspect ratios across devices.
- **LogoLoop**: An infinite scrolling logo marquee optimized for mobile and desktop viewports.
- **CircularGallery**: An interactive circular image gallery with fine-tuned scroll sensitivity using GSAP.
- **Team Section**: Features grayscale-filtered professional team imagery.

## Technologies Used
- Next.js (React)
- Tailwind CSS & PostCSS
- GSAP (for scroll-linked animations)
- Lucide React (for icons)
